# 📖 My Book — Personal Life OS & Digital Sanctuary

> **“Your Life. Your Story.”**  
> A personal operating system and digital sanctuary for documenting life, memories, goals, finances, projects, and personal knowledge.

---

## ✨ Features

- **🔐 Private & Secure Sanctuary**: Authentication system with demo profile, custom account creation, and a secure PIN-protected Document Vault.
- **📊 Executive Dashboard**: High-level overview of life metrics, daily quotes, quick journal logging, and key milestones.
- **🖊️ Daily Journal**: Reflective daily log entries with mood tracking and tagging.
- **📸 Memories & Timeline**: Capture and relive precious moments with tags and dates.
- **🧭 Travel Logs**: Document adventures, places visited, and upcoming travel bucket lists.
- **💳 Expense & Money Management**: Keep track of income, expenses, budgets, and savings goals.
- **🎓 College & Academic Hub**: Track courses, GPA, assignments, and campus life notes.
- **⚡ Skills & Learning**: Roadmaps, progress tracking, and skill acquisition logs.
- **💻 Projects Portfolio**: Catalog coding projects, side hustles, and creative endeavors.
- **🎯 Goal Tracker**: Set and monitor short-term and long-term milestones.
- **📚 Knowledge & Notes**: Second-brain notes repository for books, articles, and thoughts.
- **👥 People & Relationships**: Keep notes on meaningful connections and contacts.
- **✅ Tasks & Reminders**: Daily task manager with prioritization and checklist tracking.
- **🔒 Document Vault**: Encrypted/PIN-locked digital repository for sensitive documents.
- **📈 Life Analytics**: Visual charts and trends reflecting habits, finances, and journal activity.
- **⏪ Life Replay**: Interactive recap tool to look back over memories and achievements.
- **🤖 Ask My Book (AI Assistant)**: Query and interact with your personal life logs.

---

## 🛠️ Built With

- **HTML5 & Vanilla CSS3**: Glassmorphism design system, particle background canvas, and responsive layout.
- **Modern JavaScript (ES6+)**: Client-side single page architecture with local storage persistence and SHA-256 hashing.
- **Icons & Typography**: Lucide Icons, Google Fonts (*Outfit* & *Playfair Display*).

---

## 🚀 Getting Started

No build step or dependencies required!

1. Clone or download the repository:
   ```bash
   git clone https://github.com/<your-username>/my-book-os.git
   ```
2. Navigate to the project directory:
   ```bash
   cd my-book-os
   ```
3. Open `index.html` in any modern web browser or use a local live server:
   - Double-click `index.html` to view directly, OR
   - Run with VS Code Live Server / `npx serve .`
